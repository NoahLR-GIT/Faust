Faust Gmail Integration

A private, single-user tool for one mailbox. Not a public service.

What this is

Faust is a personal assistant that runs locally on its owner's own computer. This Google Cloud project exists so that Faust can read and send email on behalf of exactly one person, the account holder who created it.

What it does

  • Reads messages in the owner's mailbox so it can summarise, file and act on them.
  • Sends mail only when the owner has read the message and approved it.
  • Uses Google Drive, Calendar and Tasks alongside Gmail for the same owner.

What it does not do

  • It does not serve other users. There is no sign-up and no multi-tenant service.
  • It does not sell, share or publish mailbox contents.
  • It does not use mailbox contents to train machine learning models.
  • It does not operate on anyone else's account.

Where the data lives

Credentials and any cached content stay on the owner's own machine. Mail is processed to produce the owner's own summaries and drafts. Nothing is stored on a third-party server operated by this project, because there isn't one.

Privacy

What is collected, how it is used, and how it is protected are set out in the privacy policy.
